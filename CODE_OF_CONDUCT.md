# Code of Conduct

This project is the shared automation home for the Muffy1 repositories.
People and agents that open issues, pull requests, and discussions here are
expected to:

- Keep feedback on the change, the script, or the workflow.
- Assume the other person is trying to ship something useful.
- Share repro steps and logs when something fails. Redact tokens, keys, and
  personal data before pasting a log.
- Leave credentials, private repos, and customer data out of issues.
- Accept a "no" on changes that weaken branch protection, secret handling, or
  the safety checks in the CLI agent installer.

Maintainers may edit or close reports and pull requests that do not meet this
bar. Report conduct problems through a private GitHub security advisory on
this repository, described in [SECURITY.md](SECURITY.md), or by contacting the
repository owner.
